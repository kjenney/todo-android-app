# Usage Guide

## Adding a Todo

1. Tap the floating action button (FAB) in the bottom right
2. Enter the todo text
3. (Optional) Set due date and time using the date/time pickers
4. (Optional) Configure recurrence pattern:
   - Select recurrence type (None, Hourly, Daily, Weekly, Monthly, Yearly)
   - Set interval (e.g., every 2 days)
   - For weekly: select specific days of the week
5. Enable/disable notifications
6. Tap "Save"

## Editing a Todo

1. Tap on any todo item in the list
2. The edit screen opens with all current values pre-filled
3. Modify any fields you want to change
4. Tap "Update" to save changes
5. Changes are reflected immediately in all views

## Managing Todos

- **Complete**: Tap the checkbox next to a todo
- **Edit**: Tap anywhere on a todo item to edit its details
- **Delete**: Tap the trash icon
- **View Details**: Todos show due date and recurrence info below the text

## Viewing Modes

### Today's Todos (Default)
Shows only todos due today for focused task management.

- Access: Launches by default, or Menu → Today's Todos

### All Todos
View all todos regardless of due date.

- Access: Menu → All Todos

### Calendar View
Visual calendar interface showing todos across time.

- Access: Menu → Calendar View
- Tap any date to see todos for that day
- Navigate between months
- See which dates have todos

### Weekly Waterfall View
View the current week in a flowing waterfall layout.

- 7 vertical day columns
- Todos cascade down each day by time
- Color-coded status (green=complete, blue=pending, red=overdue)
- Navigate between weeks with arrow buttons
- Horizontal scrolling to view all days

## Filter Options

### Hide Completed

Toggle to hide/show completed todos:

- Access: Menu → Hide Completed (checkable option)
- Applies to all view modes (Today, All Todos, Calendar)
- Useful for focusing on active tasks
- State persists while app is running

## Adding Widgets

### Todo List Widget

1. Long press on home screen
2. Select "Widgets"
3. Find "Todo App" → "Today's Todos" widget
4. Drag to desired location
5. Widget shows today's todos and updates automatically

**Widget Features:**
- View today's todos from home screen
- Check off items without opening app
- Auto-updates when todos change
- Resizable to fit your layout

### Calendar Widget

1. Long press on home screen
2. Select "Widgets"
3. Find "Todo App" → "Calendar" widget
4. Drag to desired location

**Widget Features:**
- Current month calendar view
- Days with todos show dot indicators
- Today highlighted in purple
- Shows up to 5 of today's todos below calendar
- Tap to open app

## Seeding Sample Data

For testing or demonstration purposes:

1. Open the app
2. Tap Menu (three dots)
3. Select "Seed Sample Todos"
4. Confirm the dialog
5. ~25 sample todos will be added across the current week

This is useful for:
- Testing the waterfall calendar view
- Demonstrating features
- Development and testing

## Tips and Tricks

### Recurring Tasks
- Set up recurring tasks once and they auto-create
- Complete a recurring todo to generate the next occurrence
- Edit the parent to change all future occurrences

### Notifications
- Enable notifications per todo for important deadlines
- Notifications appear at the exact due time
- Mark todos complete directly from notifications
- See [Permissions](permissions.md) for reliable notification setup

### Organization
- Use the "Hide Completed" filter to focus on active tasks
- Switch to "All Todos" to review everything
- Use the calendar view for long-term planning
- Use the waterfall view to see your week at a glance
